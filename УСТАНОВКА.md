# Хорео — установка на iPhone без App Store

Приложение — это сайт, который добавляется на экран «Домой» и дальше работает как обычное приложение:
на весь экран, со своей иконкой, **без интернета**. Все постановки и музыка хранятся на самом телефоне.

**Адрес приложения:** https://usmanovdenis21-afk.github.io/choreo/
(уже выложено — шаг 1 выполнен, переходите к шагу 2)

## Шаг 1. Выложить файлы в интернет (один раз, бесплатно)

Нужен любой хостинг с HTTPS. Проще всего — GitHub Pages:

1. Зарегистрироваться на https://github.com (бесплатно).
2. Нажать **New repository** → имя, например `choreo` → **Public** → **Create repository**.
3. На странице репозитория: **uploading an existing file** → перетащить из папки `хорео`:
   `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest` и папку `icons`
   (папку `.claude` и этот файл загружать не нужно) → **Commit changes**.
4. **Settings → Pages → Branch: main, папка / (root) → Save**.
5. Через 1–2 минуты появится адрес вида `https://ВАШ-ЛОГИН.github.io/choreo/`.

## Шаг 2. Установить на iPhone

1. Открыть этот адрес в **Safari**.
2. Кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **Добавить**.
3. Запускать с иконки «Хорео». После первого запуска интернет не нужен.

## Как пользоваться

- **Танцоры** — добавить людей (можно списком через запятую), цвета, группы.
- **Сцена** — размер площадки в метрах, шаг сетки, размер фигур.
- **Музыка** — загрузить трек из «Файлов» (mp3/m4a/wav), указать BPM (или «Тап-темп») и где первый счёт «1».
- **+ Формация** — копирует текущую расстановку, дальше двигайте людей пальцем.
  Пунктиром показан путь из прошлой формации.
- Длительность формации и перехода — во вкладке **Формация**, в счётах.
- ▶ — проигрывание с музыкой и плавными переходами. Скорость 0.5× / 0.75× для разучивания.
- Кнопка выбора нескольких (левый верхний угол) → касайтесь танцоров → двигайте вместе;
  внизу появятся «Зеркало», «В ряд», «В колонну», «Обмен».
- **Поделиться** (вверху справа) → PNG формации или PDF всех формаций → отправить в Telegram/WhatsApp.

## Важно про данные

- Постановки живут только на этом телефоне. Если удалить иконку с экрана «Домой» — данные удалятся.
- Время от времени делайте **Поделиться → Файл постановки** и сохраняйте его в «Файлы»/iCloud.
  Его же можно открыть на другом устройстве («Открыть файл постановки»).

## Обновление приложения

После изменения файлов загрузите их на GitHub заново и поменяйте в `sw.js` строку
`const VERSION = 'choreo-v1'` на `choreo-v2` (v3 и т. д.).
На телефоне новая версия появится после второго запуска приложения.
